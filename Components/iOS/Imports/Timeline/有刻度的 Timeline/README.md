# 有刻度的 Timeline

A reference import for the tick-marked timeline interaction on [pengzhe.ng](https://www.pengzhe.ng/cn#timeline).

- `Original source code/` — downloaded compiled production JS, its direct JS dependencies, and relevant CSS.
- `Preview/` — notes and entry point for the upstream browser preview.

This is an imported learning reference, not yet a native SwiftUI component and not yet a standalone local web demo. See the source folder README for provenance and licensing caveats.
