# Card Imports

Exploratory card components imported or adapted from external references. These remain separate from production components until reviewed and integrated.

- `ReflectiveCard/`: native SwiftUI exploration inspired by React Bits Reflective Card, with the Rose tint preset.
- `../SwiftPiecesOriginals/`: imported Swift Pieces implementations, kept separately at the same level as this folder.
- `CardStacks/DepthCarousel/`: original React Bits Depth Carousel TypeScript/CSS source and registry snapshot; reference-only, not yet ported to SwiftUI. See its README for provenance and license.
