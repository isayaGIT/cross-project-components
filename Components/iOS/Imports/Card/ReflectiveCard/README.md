# ReflectiveCard — Original React Bits source

This folder now contains the original React Bits implementation, copied without rewriting its rendering logic:

- `ReflectiveCard.jsx` — original WebGL renderer, shaders, video/webcam capture, pointer/touch interaction, and component implementation.
- `ReflectiveCard.css` — original styles.

Source: [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits/tree/main/src/content/Components/ReflectiveCard)

Dependencies used by the original component: `@hugeicons/react` and `@hugeicons/core-free-icons`. It also imports its sibling CSS file. The component is React/WebGL source and is not a native SwiftUI component; use it in a React web preview/runtime. Do not treat the separate Swift approximation as the original implementation.
