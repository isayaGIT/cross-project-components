# CharacterName

Reusable typography for user and character names. Font family, size, color, and weight are supplied by the caller. Dynamic/paid-member text effects are intentionally left as a future extension.

```swift
CharacterName(
    "林知夏",
    style: .init(fontName: "AvenirNext-DemiBold", fontSize: 20, color: .primary, weight: .semibold)
)
```
