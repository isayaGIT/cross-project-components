# Background

`Background` composes a component background from an image, remote image URL, SwiftUI `Material`, or `ColorCustom`. `ColorCustom` supports solid colors and linear, radial, and angular gradients.

```swift
Background(color: .blue)
Background(material: .ultraThinMaterial)
Background(color: ColorCustom(style: .linearGradient(colors: [.purple, .blue])))
```
